**Key finding:** The live page has no meta description and no meta keywords tag — two basic on-page SEO elements. Google uses the meta description for snippets; its absence means Google auto-generates one from body text (usually worse). The live page title is also 98 characters — Google truncates around 60.

## 7. Top Recommendations for the Local File

1. **Add FAQ JSON-LD schema** — the FAQ section is already there; wrapping it in `FAQPage` schema is ~20 lines of JSON and can unlock rich results in Google SERPs.
2. **Add LocalBusiness + Service schema** — address, phone, BBB rating, and service area are all known; schema makes them machine-readable for Google.
3. **Add BreadcrumbList schema** — breadcrumb is already visually present; marking it up gets the breadcrumb shown in Google SERPs.
4. **Consider adding `Employment Verification`** to the title or a heading — the live page targets this term and it reflects a real search intent.
5. **Add at least one keyword-optimized image with descriptive alt text** — the live page beats the local file on this dimension.
